# Snipt

Share code in seconds. No login required.

A simple code sharing platform built with **PHP** that lets you create secure, shareable code snippets instantly.

</div>

---

## Why I built this

I've often found myself sharing code through Discord, WhatsApp, Slack, or email. Screenshots lose formatting, large snippets become messy, and creating a GitHub repository just to share a few lines of code feels like overkill.

So I built **Snipt**.

It lets you paste your code, generate a shareable link, optionally protect it with a password, and even set it to expire automatically—all without requiring an account.

This was also my **first project built with PHP**, making it a great opportunity to learn a new backend language while solving a real problem I face regularly.

---

## Features

- ⚡ Share code instantly
- 🔒 Optional password protection
- ⏳ Expiring links
- 📦 Upload ZIP archives
- 🎨 Automatic language detection
- 📋 One-click copy
- 🛡️ Secure input handling
- 📱 Responsive interface
- 🚫 No signup required

## Running Locally

Clone the repository

```bash
git clone https://github.com/tavishnew/Snipt.git
cd Snipt
```

Start a local PHP server

```bash
php -S localhost:8000
```

Open your browser and visit

```
http://localhost:8000
```
